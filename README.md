## Quick Start

```
Open index.html in Chrome → F11 for fullscreen
```

## Presentation Controls

| Key | Action |
|-----|--------|
| `→` / `Space` / `Click` | Next step or slide |
| `←` | Previous step |
| `F` | Toggle fullscreen |
| `R` | Restart presentation |
| `P` | Pause / resume |
